# 教室効果音アプリ

授業をもっと盛り上げたい！　そんなときに活躍するアプリです。
ボタンを押すだけで効果音が鳴る，それだけのシンプルな作りにしました。

**▶ <https://uta3y3uta.github.io/classroom-sound-effects/>**

## 特長

- **100種類の効果音**から選んで，好きな場所に並べられる
- 「つくる」画面では**長押しでつまんで**，ボタンをそのまま別の場所へ移動できる
- ボタンの数は**1×1から8×8（最大64個）**まで自由に変更（はじめは4×4の16個）
- アイコンの色は**32色のネオンカラー**から。1つずつでも「全部」まとめてでも変えられる
- 色の四角やパレットの色を**つまんでボタンまで運ぶ**と，その1つだけ色が変わる
- **Ctrl＋Zでもとにもどす／Ctrl＋Yでやりなおす**（60回前までさかのぼれる）。
  Ctrlキーのないタブレット向けに，**ゴミ箱のとなりに戻る／進むボタン**も置いてあります
- **「使う」と「つくる」の2画面**。授業中は誤操作しない「使う」画面のまま
- **共有URLを発行**すれば，並べ方も色もそのまま同僚に渡せる
- 音量スライドバー，ワンタップのミュート，鳴っている音をすぐ止めるSTOPボタン
- 同じボタンを**連打**すると前の音を切って鳴り直すので，音が重なって濁らない
- 並べ方はブラウザに自動保存。次に開いたときも同じ状態
- インストール不要。スマホ・タブレット・PCどれでも動作

## 使い方

1. 上記のURLを開く
2. 鳴らしたいボタンをタップ
3. 並べ替えたいときは右上の**「つくる」**へ。ボタンを押すと音の一覧が開きます
4. ボタンを**長押し**すると，つまんだまま動かして別の場所と入れかえられます
5. 「ならべかた」の＋−でボタンの数を変更
6. 「色」のとなりの四角を押すと32色のパレットが開きます。色の使い方は3とおり
   - はじめは**「ー」**（どこにもかけない）が選ばれています。この状態で色をタップしても
     画面は変わらず，**運ぶための色を手に持つだけ**。うっかり全部が染まる心配はありません
   - 「全部」か番号を選んでから色をタップ＝そこにまとめて色がつきます
   - **色の四角をそのままつまんで，変えたいボタンまで運ぶ**＝その1つだけ色が変わります
     （パレットを開かなくても運べます。押してはなすだけならパレットが開きます）
   - パレットの色を**長押しでつまんで運ぶ**＝同じく，その1つだけ色が変わります
   - どちらも運んでいる間はボタンの色が先に変わるので，置く前に見くらべられます
   - 消しゴムアイコンでもとの色にもどります
7. 右上の共有アイコンで，いまの並べ方と色を再現するURLをコピー

※ iPhone・iPadでは，はじめの1タップで音が有効になります。

※ **もとにもどす／やりなおす**は，ゴミ箱の左どなりの矢印ボタンから。パソコンなら
**Ctrl＋Z**（Macは⌘＋Z）でもどり，**Ctrl＋Y**または Ctrl＋Shift＋Z でやりなおせます。
並べかえ・音の入れかえ・ボタンの数・色が対象です（音量とミュートは対象外）。

- グループ活動の開始・終了の合図に**ホイッスル**や**ゴング**

**素材への変更点**

- 長すぎる音（学校のチャイム，拍手，サイレンなど）を教室で使いやすい長さに短縮し，末尾にフェードをかけています
- 「エアホーン」は連打して「ポン，ポン，ポーン」と鳴らせるよう，一発を0.70秒に切り詰めています
- 「ピンポン」はもともと2回コールなので，1回目のうしろに2回目の余韻をつないで1回に詰めています
- 「ジャンプ」「チャリン」「パワーアップ」の3音は，このアプリ用に合成したチップチューンです
  （素材配布元・ゲーム会社とは無関係の自作音です）
- 「ピー」「ピロピロ」は自主規制音です。もともと電子的な信号音なので，正弦波から合成しています
- 「イヨー」「プラスワン」は鈴木優太が録音・作成した音源を，前後の無音を切って音量をそろえたものです

このアプリを再配布・改変する場合も，上記のクレジット表記を残してください。

## 技術メモ

静的ファイルのみで動作します（ビルド不要）。

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `styles.css` | 見た目。グリッドはコンテナクエリでパッドが正方形に近くなるよう調整 |
| `icons.js` | 使用するLucideアイコンのSVGのみを抽出したもの |
| `catalog.js` | 100音のメタデータ（名前・カテゴリー・アイコン・音量補正値・検索語） |
| `app.js` | 再生・編集・共有URL |
| `version.json` | 現在の版番号。開いている画面が古くないかを確かめるために使う |
| `sfx/` | 効果音のMP3（100ファイル・合計約4MB） |

- 再生はWeb Audio API。リミッターを挟み，音割れを防いでいます
- 音量は全100音を実測し，EBU R128の瞬時ラウドネス（400ミリ秒窓）の最大値が−10.5LUFSに
  そろうよう補正値を `catalog.js` に持たせています（真のピークは−1dBFSで頭打ち）。
  ファイル全体の平均音量でそろえる方式だと，寺の鐘のように響きの長い音が過剰に絞られました
- 共有URLは「列数・行数・各マスの音番号」をbase64urlに詰めたもの（8×8でも90文字程度）
- 色はそのうしろに足しています。全部が既定の色なら1バイトも足さず，「全部」で染めたときは
  2バイトだけ（8×8で92文字）。1マスずつ変えたときだけ1マス1バイト使います（同176文字）。
  うしろに足す形なので，色を知らない古い版のアプリでも読み飛ばして並べ方だけ正しく開けます
- 共有URLの先頭にはバージョン番号を持たせ，音の入れ替えで番号の意味が変わったときは
  古いURLを読み込まない設計です（誤って別の音が鳴るのを防ぐため）。現在はバージョン7
- CSS・JS・MP3の読み込みには `?v=19` を付けています。音や画面を更新したときは
  `index.html` の `ASSET_VER` と各タグの `v`，そして `version.json` の数字を
  **3か所そろえて**上げてください。
  上げないと，一度開いたことのある端末でブラウザのキャッシュが残り，前の音が鳴り続けます
- `index.html` 自体にはGitHub Pagesの既定で10分のキャッシュが効きます。版番号を持っているのが
  その `index.html` なので，`?v=` を上げるだけでは更新直後の端末に届きません。
  そこで版番号だけを `version.json` に切り出し，起動時にキャッシュを通さず読みに行って，
  数字が上がっていれば `?v=` 付きのURLで一度だけ読み直すようにしています
