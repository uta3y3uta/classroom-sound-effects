# 教室効果音アプリ

授業をもっと盛り上げたい！　そんなときに活躍するアプリです。
ボタンを押すだけで効果音が鳴る，それだけのシンプルな作りにしました。

## 特長

- **4×4の16ボタン**。アイコンと音の名前を，デジタルネオン調のカラフルなデザインで表示
- **音量スライドバー**と**ワンタップのミュート**を画面下部に配置
- 再生中の音をすぐ止める**STOPボタンつき**
- **音源ファイルを一切使わない**（すべてブラウザのWeb Audio APIで合成）
  - 読み込み待ちゼロ，通信量ゼロ，著作権の心配なし
- インストール不要。URLを開くだけで，スマホ・タブレット・PCどれでも動作

## 収録している効果音（16種）

| | | | |
|---|---|---|---|
| 🥁 ドラムロール | ⚡ ジャジャーン | ⭕ ピンポーン | ❌ ブー |
| 😱 ガーン | 🦘 ジャンプ | 🪙 コイン | 🍄 1UP |
| 🎺 テッテレー | ✨ キラーン | 🙌 歓声 | 🏆 表彰式 |
| 📯 ファンファーレ | ⏳ チーン | 👏 拍手 | 🪘 和太鼓 |

## 使い方

1. 上記のURLを開く
2. 鳴らしたいボタンをタップ
3. 音量は下のスライドバーで調整。スピーカーのアイコンを押すとミュート

※ iPhone・iPadでは，はじめの1タップで音が有効になります。

## 教室での使いどころ

- 発表前の**ドラムロール**で期待感を高める
- 答え合わせに**ピンポーン**と**ブー**
- 係活動の表彰やクイズ大会に**ファンファーレ**と**拍手**
- 授業の締めくくりに**チーン**で時間を知らせる

## 技術メモ

`index.html` 1ファイルのみで完結しています。
効果音はすべてオシレーター・ノイズ・FM合成・コンボルバーによるリバーブを組み合わせて
その場で生成しているため，既存の音源データは含んでいません。
