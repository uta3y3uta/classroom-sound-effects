# 教室効果音アプリ

授業をもっと盛り上げたい！　そんなときに活躍するアプリです。
ボタンを押すだけで効果音が鳴る，それだけのシンプルな作りにしました。

**▶ <https://uta3y3uta.github.io/classroom-sound-effects/>**

## 特長

- **100種類の効果音**から選んで，好きな場所に並べられる
- ボタンの数は**1×1から8×8（最大64個）**まで自由に変更（はじめは4×4の16個）
- **「使う」と「つくる」の2画面**。授業中は誤操作しない「使う」画面のまま
- **共有URLを発行**すれば，並べ方ごとそのまま同僚に渡せる
- 音量スライドバー，ワンタップのミュート，鳴っている音をすぐ止めるSTOPボタン
- 同じボタンを**連打**すると前の音を切って鳴り直すので，音が重なって濁らない
- 並べ方はブラウザに自動保存。次に開いたときも同じ状態
- インストール不要。スマホ・タブレット・PCどれでも動作

## 使い方

1. 上記のURLを開く
2. 鳴らしたいボタンをタップ
3. 並べ替えたいときは右上の**「つくる」**へ。ボタンを押すと音の一覧が開きます
4. 「ならべかた」の＋−でボタンの数を変更
5. 右上の共有アイコンで，いまの並べ方を再現するURLをコピー

※ iPhone・iPadでは，はじめの1タップで音が有効になります。

いずれも再配布が許諾されている素材のみを使用しています。
アプリの画面上には表示していないため，再配布・改変の際はこのREADMEのクレジットを必ず残してください。

**素材への変更点**

- 長すぎる音（学校のチャイム，拍手，サイレンなど）を教室で使いやすい長さに短縮し，末尾にフェードをかけています
- 「レゲエホーン」は連打して「ポン，ポン，ポーン」と鳴らせるよう，一発を0.70秒に切り詰めています
- 「ネコ」はOtoLogicの「猫 合成01」を，音程を変えずに約2.3倍へ時間伸長（WSOLA）して
  「にゃ～お～」と伸びる鳴き方にしています
- 「ジャンプ」「コイン」「１UP」の3音のみ，このアプリ用に合成したチップチューンです（素材配布元とは無関係）

このアプリを再配布・改変する場合も，上記のクレジット表記を残してください。

## 技術メモ

静的ファイルのみで動作します（ビルド不要）。

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `styles.css` | 見た目。グリッドはコンテナクエリでパッドが正方形に近くなるよう調整 |
| `icons.js` | 使用するLucideアイコンのSVGのみを抽出したもの |
| `catalog.js` | 100音のメタデータ（名前・カテゴリー・アイコン・音量補正値・検索語） |
| `app.js` | 再生・編集・共有URL |
| `sfx/` | 効果音のMP3（100ファイル・合計約4MB） |

- 再生はWeb Audio API。リミッターを挟み，音割れを防いでいます
- 音量は全100音を実測し，ピークが−1dBを超えない範囲で平均−20dBにそろえる補正値を
  `catalog.js` に持たせています
- 共有URLは「列数・行数・各マスの音番号」をbase64urlに詰めたもの（8×8でも90文字程度）
- 共有URLの先頭にはバージョン番号を持たせ，音の入れ替えで番号の意味が変わったときは
  古いURLを読み込まない設計です（誤って別の音が鳴るのを防ぐため）。現在はバージョン4
